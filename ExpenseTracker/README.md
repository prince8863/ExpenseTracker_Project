# Expense Tracker - Mini Java Project

A simple Expense Tracker mini-project made for a college Java practical/project.

## Technologies

- HTML
- CSS
- JavaScript
- Basic Java

## Frontend Features

- Dashboard
- Total expenses
- Transaction count
- Average expense
- Add expense
- Expense history
- Delete expense
- Category summary
- LocalStorage for browser data

- Constructor
